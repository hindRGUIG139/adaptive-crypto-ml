# Adaptive Crypto ML

Adaptive Crypto ML is a machine learning project that selects the most suitable encryption algorithm based on the execution context.

Currently implemented:
- AES-128 (CTR mode)
- ChaCha20
- PRESENT-80 (CTR mode)
- Benchmarking for execution time comparison

The project aims to generate performance data that will be used to train a Machine Learning model for adaptive encryption selection.
